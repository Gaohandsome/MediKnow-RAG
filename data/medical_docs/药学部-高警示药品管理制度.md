# 高警示药品管理制度

> 【合成演示数据】本文件由项目脚本生成，仅用于系统演示与测试，不可用于临床决策。

## 一、管理目标与适用范围

高警示药品指使用不当易导致患者严重伤害或死亡的药品。本制度适用于本院药库、静脉用药调配中心、门急诊药房、各病区及手术室的采购、储存、处方、调配、给药与监测全过程。

管理目标：

1. 消除「相似药品混淆」与「剂量数量级错误」两类高频差错。
2. 让每一支高警示药品的流向可追溯、每一次给药可复核。
3. 把差错从事后追责转为事前拦截与事中提醒。
4. 建立统一的标识、专区、双人核对与监测规则，避免各科室自行其是。

本制度由药学部牵头制定，护理部、医务处共同监督执行，纳入医院患者安全目标年度考核。

## 二、目录范围

本院高警示药品目录包括：

1. 胰岛素类制剂（含速效、长效及预混胰岛素）。
2. 高浓度电解质：10% 氯化钾、10% 氯化钠、25% 硫酸镁。
3. 抗凝药物：普通肝素、低分子肝素、华法林。
4. 化疗药物与免疫抑制剂。
5. 镇静催眠药与阿片类镇痛药。
6. 高渗葡萄糖（50%）与静脉营养制剂。

目录每年由药事管理与药物治疗学委员会复核一次。

目录还需同步以下配套信息：药品通用名与商品名对照、常用极量、常见差错类型、特殊储存条件。新增药品须在信息系统中同步标记「高警示」属性，未标记不得入库。

## 三、储存与标识

- 专柜存放，专区加锁，标识统一为红底白字「高警示」。
- 10% 氯化钾注射液不得与普通电解质混放，单独定位存放。
- 病区备用高警示药品实行基数管理，每日清点并双人签名。
- 相似包装、相似读音药品（如胰岛素各剂型）分开摆放并加警示标签。

储存细节要求：

1. 胰岛素未开封者 2~8 ℃ 冷藏，不得冷冻；开封后室温保存不超过 28 天，标注开启日期。
2. 高浓度电解质使用专用分隔盒，盒外标注浓度与总量。
3. 麻醉药品与第一类精神药品按《麻醉药品和精神药品管理条例》实行五专管理。
4. 化疗药物单独存放，配备溢出处理包与个人防护用品。
5. 效期管理执行「先进先出、近效期先用」，距离失效 3 个月的药品挂黄色标识。

## 四、处方与调配

1. 高警示药品处方需注明适应证、用法用量与滴速。
2. 调配实行双人独立核对，核对内容包括药品名称、规格、剂量、浓度与给药途径。
3. 10% 氯化钾禁止静脉推注，必须稀释后经中心静脉或大静脉缓慢滴注，浓度不超过 0.3%，速度不超过 20 mmol/h。
4. 化疗药物由静脉用药调配中心集中配置，操作人员做好职业防护。

处方审核要点：

- 信息系统对超极量处方强制弹窗，需上级医师二次确认方可提交。
- 肾功能不全、老年、低体重患者的剂量需按肌酐清除率或体重调整。
- 胰岛素医嘱必须写明「单位」，禁止使用「U」「IU」等易混淆简写。
- 化疗医嘱需核对体表面积、疗程与累积剂量，超累积剂量者需专科会诊。
- 手写处方一律不予调配，抢救情况下可由双人核对后先行给药并补录。

## 五、给药与监测

- 给药前双人核对患者身份、药物与泵入参数，泵入管路标识清晰。
- 胰岛素静脉泵入需每小时监测血糖；肝素泵入需每 4~6 小时监测活化部分凝血活酶时间。
- 输注高浓度电解质期间持续心电监护，观察穿刺部位有无外渗。
- 发生外渗立即停止输注、回抽药液并按外渗处理流程处置。

监测要求补充：

1. 泵入类高警示药品使用专用输液泵，参数由两人独立设置并复核。
2. 管路标识注明药品名称、浓度、配制时间与配制人。
3. 阿片类药物给药后监测呼吸频率与镇静评分，警惕呼吸抑制。
4. 华法林治疗期间监测 INR，目标范围按适应证个体化设定。
5. 化疗药物输注期间每 15 分钟巡视一次，观察过敏反应与外渗征象。

## 六、相似药品与特殊人群管理

1. 建立本院相似药品清单，包括外观相似、读音相似、规格相似三类，每半年更新。
2. 相似药品在货架与信息系统均需加注「易混淆」标签，调配时强制二次扫码。
3. 儿童用药按体重或体表面积计算，禁止按成人剂量减半估算。
4. 老年患者起始剂量取下限，注意药物蓄积与相互作用。
5. 妊娠期与哺乳期用药需经处方审核药师与主管医师共同确认。

## 七、外渗与过量应急处置

1. 外渗立即停止输注，保留针头回抽残留药液，拔针后局部按压，不得热敷或按摩（特殊拮抗方案除外）。
2. 按药品性质选择拮抗剂，如化疗药物外渗使用相应解毒剂并请专科会诊。
3. 外渗部位拍照记录、测量范围，每班观察皮肤颜色与感觉变化。
4. 疑似过量给药立即停药、评估生命体征、留取血标本并通知药师参与救治。
5. 胰岛素过量导致低血糖按低血糖流程处理，必要时持续静脉输注葡萄糖并监测血糖至少 24 小时。

## 八、不良事件管理

- 高警示药品相关差错无论是否造成后果，均须 24 小时内上报药学部与护理部。
- 每季度汇总分析差错类型，纳入患者安全改进项目。
- 新入职人员须完成高警示药品专项培训并考核合格后方可独立操作。

上报与分析要求：

1. 上报内容包括差错环节、涉及药品、发现方式、是否到达患者与后果。
2. 鼓励主动上报，非故意差错且主动上报者不予处罚。
3. 每季度按差错环节分类统计，优先改进「处方—调配—给药」三段的高频断点。
4. 典型差错制作成教学案例，纳入全院用药安全培训。

## 九、培训与质控指标

1. 全员每年完成一次高警示药品培训，药师与护士每半年一次。
2. 新入职、转岗、进修人员上岗前必须通过书面与实操考核。
3. 质控指标包括：双人核对执行率、专用标识符合率、泵入参数复核率、差错上报率。
4. 药学部每月抽查 30 份高警示药品医嘱，核对适应证、剂量与监测记录。
5. 每季度开展一次高警示药品专项检查，结果纳入科室质量考核并公示。
